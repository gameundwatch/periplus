# here

まだ決着していない記述が periplus に留まること。

出口ではなく docs の保留形である。決着していない記述は文書が課す試験を通らず、
通してしまえば未決の問いが決定として記録に入る。留まっていること自体が、その決定が
まだ誰かに負われていることの記録になる。

同じ主題が二度目に落ちたとき、それが文書を書く根拠になる。記述一件は文書を作る理由に
ならないが、一つの主題に二件はなる。periplus はその証拠が溜まる場所である。
