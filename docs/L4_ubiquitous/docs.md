# docs

periplus の記述を、そのリポジトリが既に持っている文書に足すこと。

行き先の文書はリポジトリごとに異なり、既定は無い。ADR を持つリポジトリで次の番号を
切ることや、既にあるロードマップに追記することは「既にある実践に足す」に含まれる。
記述一件を収めるために文書の体系を新設することは含まれない(→ here)。

**通過試験は行き先の文書が持つ。** ADR なら覆しにくい・文脈無しでは驚く・実際の
トレードオフの結果、の三つ。ロードマップなら実際に着手する意思。用語集なら
プロジェクト横断で使われる語。行き先を広げたことは、通る記述を広げる根拠にはならない。
