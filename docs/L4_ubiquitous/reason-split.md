# 理由の三分割

一つの理由がどこに属するかは、その理由を**誰が決め、どこが記録しているか**で分かれる。

- **文書の言い直し**
    - その主張を、このリポジトリの既存の文書が既に書いている。文書と行を
      名指しでき、名指しした行が同じことを述べている
- **未文書化の設計**
    - 設計が決めた理由で、どの文書もそれを記録していない
- **設計の空白を埋めた選択**
    - 設計が決めておらず、実装が裁量で決めた

三つのどれも示せない理由が残る。それが `why` であり、**残余である**。判定できなかったことを
判定できなかったまま記録する場所であって、失敗ではない。推測して三つのどれかに入れることの
ほうが、記録としては悪い。

セッションはこの判定の材料にならない。会話で言われた理由はどの文書も記録していない理由で
あって、後から読み返せる場所には無い。
