# code

periplus に退避された記述から、コード上のコメントとして存在すべき部分を
切り出してコードに書くこと。

丸ごと採用するか捨てるかの二値ではなく、**分解操作**である。一つの記述が複数の
性質を同時に含むことは多く、その場合は該当部分だけがコードに移り、残りは
periplus に残る。

主経路ではなく救済路である。periplus に入る記述は種別上コードに残らないものなので、
コードに残るべき部分がここに現れたということは、捕獲の段階で割り切れていなかった
ということを意味する。
