# 種別(kind)

pre-comment 一件が持つ、ちょうど一つの分類。閉じた集合であり、利用者が増やすことは
できない。

一つの pre-comment が二つの種別を同時に持つことは無い。二つ持つように見えるものは
分割されていないのであって、複数の種別を許すのではなく、種別が一つに定まる最小単位
まで割る。割った結果がさらに二つを含むことがあるため、分割は再帰的である。

種別は記述の主題を指す。コードの属性(古い、暫定である)を指す語を種別の名前に選ぶと、
その属性を述べた記述を名前の一致で引き寄せ、本来コードに残るべき記述が捨てられる。

種別は理論から作らず、実際に発生した pre-comment から起こす。発生しない種別は規律を
膨らませるだけで、逆に種別を持たない記述は行き場を失って別の種別に吸われる。
