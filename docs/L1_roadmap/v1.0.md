# v1.0

periplusで想定する基本機能が揃い次第、以下の内容を含めてv1.0リリースとする

## プロモーション用ページをgithub pagesに公開

- periplusロゴ(Roman系の筆記体)
- githubリポジトリのソースへのリンク
- 作者SNSリンク(X/discord)
- install方法などの端的な説明 `/plugins marketplace add gameundwatch/periplus`
- kind別のチェックボックス群、下記の(2)で表示、消去するコメントを選択できる

これに加え以下の内容を2パターン用意し、画面全体を中央下部に配置されたスライドでBefore-Afterの切り替えができる。レンダリングのBefore-Afterのような画面全体を任意の区切りでワイプさせる垂直バー

1. サイトページの説明
    - (Before)
        - AIに自由に書かせた当ツールの丁寧な説明
    - (After)
        - AIが書いた説明をこちらで精査し、過説明を抑えたシンプルな説明（periplusの本来の効果ではないが、端的にツールの性格を伝えるのに適している）

2. AI生成したコードでできた背景（レンダリングが重ければ１枚絵でもOK）
    - (Before)
        - 特に規則で縛っていない（none-periplus）素の状態のAIに書かせたコード
    - (After)
        - periplusを適用した状態でAIに書かせたコード

## Features
- [capture](../L2_features/capture.md)
    - 書いている間に溜める
- [filter](../L2_features/filter.md)
    - 溜めたものを一度に濾す
- [discuss](../L2_features/discuss.md)
    - ログを文書へ送る
- [sweep](../L2_features/sweep.md)
    - 既存のコメントを同じ経路に乗せる
- [configure](../L2_features/configure.md)
    - 行き先をリポジトリごとに変える
- [status-line](../L2_features/status-line.md)
    - 件数を常時出す
- [distribution](../L2_features/distribution.md)
    - プラグインとして配る
