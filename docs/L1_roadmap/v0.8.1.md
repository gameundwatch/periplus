# v0.8.1 — 濾す単位を、書き終えた一つの変更にする

## 出荷するもの

濾過が変更ごとに走るようになる。実装とコメントが別の差分に割れなくなり、
コメントだけのコミットが出なくなる。

## 変えるファイル

- `hooks/capture.md`
    - 末尾の二段。単位を書き、完了報告を変更ごとにする
- `skills/pp/SKILL.md`
    - frontmatter の `description` の単位
- `.claude-plugin/plugin.json`
    - `0.8.1`
- `docs/L3_spec/_completion-unit.md`
    - 実装が届いたら `_` を外し、指しているリンクを直す
- `docs/L5_adr/0006-capture-first-filter-last.md`
    - 追記一段

## 触らないもの

- **コード**
    - 変わるのは注入される散文と frontmatter の一行だけ
- **テスト**
    - 既存テストは `capture.md` の先頭行と行形式しか見ておらず、どちらも動かない
- **`CONTEXT.md`**
    - 足すのは作業の語であり、あそこは記述の語彙である
- **`docs/v0.9.0.md`**
    - 同じファイルの同じ範囲を触るため行番号が古くなるが、更新は後追いでよい

## 完了の条件

一つのタスクの中で完了報告が複数回出ること。最後に一度だけなら単位は動いていない。
検査は持たず、申告だけを見る。
