# v0.8.1 — 濾す単位を、書き終えた一つの変更にする

## Features

- [capture](../L2_features/capture.md)
    - 注入される規律に単位が入り、完了の門と報告が変更ごとになる。
      [_completion-unit](../L3_spec/_completion-unit.md) の四項目
- [filter](../L2_features/filter.md)
    - `/pp` の起動条件の単位が、注入された規律と揃う

## 入れないもの

- **`docs/v0.9.0.md`**
    - 同じ範囲を触るため行番号が古くなるが、更新は後追いでよい
- **テストの追加**
    - 変わるのは散文であり、既存のテストは動かない

## 完了の条件

一つのタスクの中で完了報告が複数回出ること。最後に一度だけなら単位は動いていない。
検査は持たず、申告だけを見る。
