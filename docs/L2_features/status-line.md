# status-line — 件数を常時出す

ログの件数と、まだ濾していない記述の件数を画面に出し続ける。セッション開始時の一行は
すぐ古くなるが、こちらは古くならない。

## できること

- 濾し忘れたまま次の作業に入っていないか、いつでも見える
- 頼むまで勝手には入らない
- 既にあるステータスラインを壊さずに足せる

    - 出す形と、出さない条件
