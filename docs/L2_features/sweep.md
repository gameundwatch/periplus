# sweep — 既存のコメントを同じ経路に乗せる

`/pp-refactor` で起動する。既に書かれているコメントを切り出し、捕獲したものと同じ手順で
濾す。periplus を後から入れたリポジトリのための機能。

## できること

- 既存のコメントを、種別ごとに残す・ログへ回す・捨てるへ振り分けられる
- 範囲を自分で決められる。リポジトリ全体を一度に取られることはない
- 切り出した記録が、捕獲した記録と混ざらない

## Contract
- [pp-refactor](../L3_spec/pp-refactor.md)
    - 範囲の決め方、切り出しの単位、保管の分け方

## Design
- [コマンドの割り方](../L3_design/commands.md)
    - 三つの道具を全部持つこと
