# discuss — ログを文書へ送る

`/pp-discuss` で起動する。ログに溜まった記述を古い順に一件ずつ見て、行き先を決める。

## できること

- 実装が裁量で決めたことを、後から文書に上げられる
- 決着していない記述はログに残せる。出口を強いられない
- 同じ主題が二度落ちたことに気づける

## Contract
- [pp-discuss](../L3_spec/pp-discuss.md)
    - 一件ずつの手順と、完了の条件
