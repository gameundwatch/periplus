# 濾すのはタスクではなく、書き終えた一つの変更ごと

ADR 0006 は「コード本体が完成した時点で一度だけ濾す」と決めたが、**完成の単位を定義しなかった。**
`hooks/capture.md` も `any piece of work` と書くだけである。定義が無いので「タスク全体」と読まれ、
細かくコミットを刻む作業形態では実装が先に入り、コメントは最後にまとめて入る。

コメントだけのコミットが生まれるのはその症状であって、軸は**実装とその説明が別の差分に割れる**こと
にある。差分の把握が困難になる。

## 決めたこと

**A. 単位は、いま書き終えた一つの変更である。**タスクではない。git ではそれが commit に一致するが、
**規律には `commit` と書かない。**periplus は git を知らず、書けばプラグインが git に縛られる。
`capture.md` が `.gitignore` を名指ししているのは workspace の生成の話であって、単位の話ではない。

**B. 門は置き換える。足さない。**「タスクを完了と呼ぶ前」は消える。文書が背後にある作業にだけ発火
する(ADR 0037)以上、コミットされずに終わったのに `pre.csv` に行が残る状態はバグであって、二つ目の
門を持つ根拠にはならない。

**C. 単位を否定形で名指しする。**

```
The unit is the code you just finished, not the task it belongs to
```

この不具合は単位が書かれていなかったために既定の読みへ倒れたもので、否定節だけがその読みを殺す。

**D. 完了報告も変更ごとにする。**ADR 0012 により periplus は検査を持たず申告しか持たない。門が変更
ごとで報告がタスクごとなら、三つの変更のうち一つで `/pp` を飛ばしても最後の一行は同じ見た目になる。

**E. `/pp` の description の単位も揃える。**description はスキル一覧として常時コンテキストに載るため、
`at the end of any coding task` が残れば注入された C と正面から食い違う。ADR 0012 が最後に名指しした
「局所の文言が一般則を黙って上書きする」形にあたる。

## ADR 0006 の反転ではない

0006 の「一度だけ」は「完成ごとに一度」と読む。根拠は「判断の根拠は完成後にしか揃わない」であって、
揃うのは**その差分が完成した時点**である。0006 が決めた二段(実装中は退避だけ・完成後に分類)は
そのまま生きており、足したのは 0006 が書かなかった単位だけである。

## Considered Options

- **門を足し、タスク完了の門も残す** — コミットせずに終わる作業を拾える。ただし ADR 0037 の下では
  それはバグであり、二つあれば先に撃つのは常にコミット側なので、タスク側は死んだ条件として残る
- **規律に `commit` と書く** — 単位が一意に決まり、読み違えようがない。ただし periplus が git に
  縛られる。引き金が「コードを書くこと」(ADR 0010)である以上、対も periplus 自身が観測する事象で
  なければならない
- **`config.json` に単位を持たせる** — リポジトリごとに切り替わる。ただし ADR 0027 の対応表は
  種別 → 行き先であって作業の単位ではなく、単位を利用側に投げれば「定義が無い」状態がそのまま戻る
- **毎回モデルが決める** — 文言が一語も増えない。定義が無いまま残るので、同じ故障が確率で戻る
- **`/pp` の後に直前のコミットへ足す(amend)** — 実装を先に刻める。ただし履歴を書き換える操作を
  規律が要求することになり、periplus が git を知らないという前提を最も強く破る
- **新語「変更(change)」を `CONTEXT.md` に立てる** — 単位に名前が付く。ただし `CONTEXT.md` の語は
  すべて*記述*の語彙であり、そこへ*作業*の語を混ぜると層が増える。語は既に 0006 にあり、
  欠けていたのは定義だけだった

## Consequences

`/pp` の実行回数がタスクあたり複数回になる。可変費であって固定費ではない。固定費は注入される 12 語
だけで、プロンプト全体を図に移す版(v0.9.0)が控えているためこの版では許容した。

**未完成のまま刻めば分離は残る。**ただし刻むこと自体が「書き終えた」の宣言なので、規律の側に穴が
あるのではなく宣言が誤っている。periplus は申告しか持たない(ADR 0012)以上、そこは元から機構の外
である。

タスク完了時の報告は無くなり、報告は変更ごとになる。**一つのタスクで報告が一度しか出ないことが、
単位が動いていない印になる。**

テストは足さない。変わるのは注入される散文と frontmatter の一行だけで、書けるのは段落の存在を見る型
になる(ADR 0036)。
