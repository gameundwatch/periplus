# v0.7.8 — v0.7.4 が置いていったテスト 2 本を直す

`node --test hooks/*.test.js` は 61 本のうち 2 本が赤い。原因はどちらも v0.7.4 の F(`3558c53`
「二重にある文を一箇所に寄せる」)で、**本文を寄せたときテスト側が `skills/pp/SKILL.md` を指した
ままになっている。**

v0.7.4 から v0.7.7 まで四版、赤いまま出荷している。v0.7.6 の loadmap は「この版と無関係なので先に
単独で直す」と書いたが、単独では走らなかった。**版に属さない作業は走らない**ので、版を与える。

## 何が赤いか

**`phase 2 is told not to translate on the way out`**(`:259`) — `readDiscipline()` すなわち
`skills/pp/SKILL.md` に `Keep the language it was captured in` を探している。v0.7.4 の F はこの規則
を「配送の規則なので `pp-resolve` に残す」と決めて `pp:32-39` を落とした。残った文言は
`Shorten it; do not translate it.`(`skills/pp-resolve/SKILL.md:45`)である。**探している文字列は
リポジトリのどこにも無い。**

**`every format template that ships is a row the hook counts as the template says`**(`:319`) —
`TEMPLATE_FILES` の各ファイルが行形式を書いていることを要求する(`:324`)。`skills/pp/SKILL.md` の
行形式は、同じ F が「ADR 0032 が四ファイル表は README のものだけにすると既に決めている」として
README に寄せた。

どちらも**規律の側は正しく、テストが古い場所を指している**。本文は直さない。

## 決めたこと

**A. 言語規則のテストは `pp-resolve` を見る。** 配送するのは `/pp-resolve` であり、F の寄せ先も
そこである。テスト名「phase 2 is told not to translate on the way out」は真のまま保たれる。

**B. `TEMPLATE_FILES` を二つの主張に割る。** 一つの定数が二つのテストに使われており、F で片方だけ
偽になった。それが四版残った理由である。

| 主張 | 見るファイル |
| --- | --- |
| 書いてある行形式が hook の数える行と一致する(`:319`) | `README` / `pp-classify` / `pp-resolve` / `pp-refactor` |
| 捕捉規則の写しがどこにも無い(`:278`) | 上の四つ + `skills/pp/SKILL.md` |

後者は前者に一つ足したものなので、定数は二本になる。

```js
const TEMPLATE_FILES = [...];                                  // 行形式
const NO_CAPTURE_COPY = [...TEMPLATE_FILES, 'skills/pp/SKILL.md'];  // 写しの禁止
```

**割らずに `skills/pp/SKILL.md` を単に外すと、写しの検査からも外れる。**行形式を持たないことと、
捕捉規則の写しが現れてよいことは別である。ADR 0033 が「記録されないまま通った」と書いた種類の穴
が、こんどはテスト側に開く。

**C. `hooks/capture.md` は行形式のリストに足さない。** 元本の行形式は
`the injected capture template leaves the kind for phase 2 to fill`(`:338`)が単独で見ており、そこ
は `captureRule()` を直接読んでいる。足せば二重に検査するだけになる。

## 変えるもの

- `hooks/periplus-activate.test.js` — `:259` の参照先(A)、`TEMPLATE_FILES` の分割(B)

一ファイル、テストだけである。

## この版で触らないもの

**本文。** 寄せ先はどれも正しい。赤いのはテストが追随していないことだけで、規律の側に直すものは
無い。

**赤いまま四版出たこと自体。** テストを緑にすることと、赤いテストが出荷を止めないことは別の問題
である。止める仕組みを入れるなら別に立てる。
