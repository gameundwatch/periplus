# v0.3.6 — `.log.md` は何であり、どう数えるか

## 概要

v0.3.5 で `unspecified-choices` を足したことで、ログに着く記述の性質が変わる。既定で
periplus に行く種別は二つから三つになり、そのうち新しい一つは未決着の設計判断である。

これが `.log.md` の現行の性格づけと衝突する。ADR 0003 は periplus を**状態**と定義し、
Consequences で「日誌が空に近いことが正常な状態になり、溜まっていることが異常を示すシグナル
になる」と書いた。`/pp-discuss:116-122` は `here` を「警戒すべき失敗モード」として扱う。

**この読みは狭い。** `.log.md` は行き場を失った記述の一時置き場であると同時に、**設計への
エスカレーション待ち・コードへの落とし込み待ちの記述の列であり、その議論のための文書でも
ある**。滞在は失敗ではなく、議論が溜まっている状態である。

同じ版で、`updated` カラムを削除する。実運用で予想以上に頻繁に切り替わり、区別の器として
機能していない。

## 決定

### 1. `.log.md` の性格づけを書き直す

ADR 0003 の**中核は生き残る** — 同じ記述が periplus と恒久層に同時に存在する瞬間は無いので
MECE は破れない。当たるのは Consequences のほうである。

- 「日誌が空に近いことが正常」→ 議論待ちの数として正当に伸びる
- 「溜まっていることが異常のシグナル」→ 未決着の設計判断の規模を言う
- 「棚卸しの中心的な仕事は出口の見えないエントリを警告すること」→ 弱まる

### 2. `here` を許容する

`/pp-discuss:112-122` は `here` を「リポジトリがそれを受ける文書を持っていないから残る」と
定め、文書の不在で正当化している。ログ自身が議論のための文書なら、この根拠は要らない。

**`here` と `docs` の境界は「決着したか」で引く。**

- **ログ** — 議論中の記述
- **docs** — 決着した決定

`docs` の三条件(hard to reverse / surprising without context / real trade-off)は「決着の
試験」としてそのまま生きる。決着していないものが通らないのは、失敗ではなく正しい挙動になる。
`unspecified-choices` は定義上まだ決着していないので、最初は `here` に居るのが正しい。

`:116-122` の「失敗モードとして警戒せよ」の段落と、「二度目に同じ主題が来たら文書を作れ」と
いう再発の対抗圧は、この境界に合わせて読み替える。

### 3. 閾値警告と `warnThreshold` を削除する

`here` を広く許容すればログは正当に伸びる。既定閾値は 10 なので、毎セッション警告が出続け、
警告は風景になって死ぬ。

件数報告そのものは残す。**現行の件数は `.log.md` と `.pre.md` の素の行数であり、それ以上の
計算をしていない**(`hooks/periplus-activate.js:115-121`)。この素朴さは保つ。

`config.json` に残るキーは `criteria` だけになる。v0.4.0 が自動生成する config もそれに従う。

### 4. `updated` カラムを削除する

行の書式は次になる。

```
- <created> `<file>:<line>` [<kind>] <the note>
```

**同時に死ぬ二段落の始末が要る。**

| 箇所 | 何を言っているか |
| --- | --- |
| `skills/pp-discuss/SKILL.md:56-58` | updated が created より後の entry は一度議論されている。その議論を蒸し返すな |
| `skills/pp-discuss/SKILL.md:146-150` | created と updated の差が、誰も見ていない entry と議論して生き残った entry を区別する唯一の手段 |

どちらも代わりを立てずに削るか、別の手段を用意するかを、この版を切るときに決める。

**移行の論点** — `ROW_RE`(`hooks/periplus-activate.js:29`)と、`.pre.md` / `.log.md` /
`.all.md` / `.swept.md` の四ファイルすべてに及ぶ。既存の行は旧書式のままなので、hook の
カウントが素通しするか、両方を読むか、書き換えるかを決める必要がある。archive は
「編集されず、決して drain されない」と定めてある(`skills/pp/SKILL.md:162-163`)ため、
書き換えはその性質と衝突する。

## 書き起こす ADR

| 番号 | 主題 | 追記先 |
| --- | --- | --- |
| 0023 | `.log.md` は議論待ちの列であり、その議論のための文書でもある | `0003` の Consequences に追記 |

0023 の中に節として収めるもの — `here`/`docs` の境界を「決着したか」で引くこと、閾値警告と
`warnThreshold` の廃止。

`updated` カラムの削除を 0023 に含めるか独立させるかは、この版を切るときに決める。書式の
変更は ADR 0013(一件一種別)や ADR 0015/0018(archive)の前提には当たらないが、四ファイル
すべてに及ぶため独立した記録に値する可能性がある。
