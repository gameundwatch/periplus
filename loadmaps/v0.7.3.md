# v0.7.3 — description を削る

## 実測

description は毎セッション skill 一覧に載る。そのコマンドを一度も呼ばないセッションでも払う。

| skill | description |
| --- | --- |
| `pp` | 832 字 |
| `pp-refactor` | 588 |
| `pp-discuss` | 448 |
| `pp-classify` | 386 |
| `pp-resolve` | 302 |
| 計 | **2,556 字** |

注入される捕捉規則は 1,635 字。v0.7.0 と v0.7.1 が削ったのは本文だけで、frontmatter には
一度も触れていない。

## 決めたこと

- description は起動条件だけを持つ。手順も、規律の説明も持たない
- 本文は触らない

## 変えるもの

五つの SKILL.md の frontmatter。

`/pp-capture` は `disable-model-invocation: true` なので一覧に載らず、この版の対象外。

## 参照

- ADR 0031 — 手順書は命令だけを持つ
- v0.7.2 — `/pp-capture` の分離
