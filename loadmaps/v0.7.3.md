# v0.7.3 — description を削る

## 実測

description は毎セッション skill 一覧に載る。そのコマンドを一度も呼ばないセッションでも払う。

| skill | 前 | 後 |
| --- | --- | --- |
| `pp` | 844 字 | **348** |
| `pp-refactor` | 587 | **249** |
| `pp-discuss` | 445 | **230** |
| `pp-classify` | 383 | **163** |
| `pp-resolve` | 301 | **171** |
| `pp-capture` | 214 | **149** |
| 計 | **2,774** | **1,310**（−53%） |

毎セッション固定費は 4,408 → **2,944** 字（−33%）。内訳は注入される捕捉規則 1,634 と
description 1,310。

## 決めたこと

- **description は起動条件だけを持つ。** いつ呼ぶか、ユーザーがどう言うか
- 落とすもの — 何をするか、内部の手順、書き込み先、境界、`Invoked as /xxx`
- 本文は触らない

## 変えたもの

六つの SKILL.md の frontmatter。
