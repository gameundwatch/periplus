# v0.7.2 — 捕捉規則を `/pp-capture` として分離する

## 決めたこと

- `skills/pp/CAPTURE.md` を `skills/pp-capture/SKILL.md` にする
- 注入される本文は変えない
- **`/pp` は `/pp-capture` → `/pp-classify` → `/pp-resolve` を通す。** v0.6.1 まで
  `skills/pp/SKILL.md` が捕捉規則を含んでいたため `/pp` は三つを覆っていた。v0.7.1 が
  規則を外に出したとき `/pp` は phase 2 だけになり、その変更は記録されていない
- `disable-model-invocation` は付けない。`/pp` から呼べなくなる。単体呼び出しは想定しない

## 変えるもの

| ファイル | |
| --- | --- |
| `skills/pp/CAPTURE.md` | 削除 |
| `skills/pp-capture/SKILL.md` | 新規。本文は `CAPTURE.md` のまま |
| `hooks/periplus-activate.js` | `CAPTURE_PATH` |
| `hooks/periplus-activate.test.js` | `no other file restates the capture rule` の走査先 |
| `skills/pp/SKILL.md` | phase 1 の在処 |
| `README.md` | 捕捉規則の在処、Commands |
